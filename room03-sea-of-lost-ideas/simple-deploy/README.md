# simple-deploy
[Uncloud](https://github.com/psviderski/uncloud) is awesome but seems too much for what I need so why not use somes components and redo it simpler ?

## Needs
- Deploy without container registry https://github.com/psviderski/unregistry
- Connect to machines using SSH and podman or docker seamlessly
- Podman/Docker agnostic
- Deploy remotely using docker-compose spec
- Rolling updates (0 downtime deployment)- Caddy reverse proxy
- deploy command and down (to take it down)
